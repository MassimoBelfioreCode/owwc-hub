# owwc-hub
🎮 Laravel MVC CRUD app for managing players, teams, matches, and statistics of the Overwatch World Cup.

**Technologies**:

- **Php** - required version > 7.0 (you can check it opening a command line interpreter and typing php --version.
  
- **Laravel**

- **MySQL**
